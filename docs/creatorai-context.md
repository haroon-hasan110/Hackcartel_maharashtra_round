# CreatorAI Context

## Product
CreatorAI is an AI-powered creator operating platform for turning one source recording into a reusable content pipeline.

## Hackathon Goal
Build a strong 24-hour MVP that clearly demonstrates:
- upload one source video
- AI analysis of the recording
- identification of strong moments
- generation of a short-form clip
- editing of AI output
- repurposing for multiple platforms
- export workflow

## Core Principle
AI does repetitive work. Creators keep final say.

## MVP Scope
The MVP must focus on one end-to-end workflow:
IDEA → SCRIPT → RECORDING → UNDERSTANDING → EDITING → REPURPOSING → REVIEW → EXPORT

## Priority Rules
- P0: must work for demo
- P1: nice to have if time allows
- P2: future roadmap only

## Demo Narrative
User uploads a long-form podcast/session video, CreatorAI finds meaningful moments, recommends clips, generates hooks/captions, lets the creator edit, adapts for Instagram/YouTube/LinkedIn, and exports a ready artifact.

## Non-goals for MVP
- Professional nonlinear editing suite
- Complete social scheduling
- Auto-publishing
- Advanced analytics
- Collaboration
- Payment systems
- Enterprise permissions
- Multi-agent orchestration

## Success Signal
A user can start with a real recording, inspect AI-detected topics and moments, edit the AI output, adapt for at least one platform, and complete an export flow within a short demo session.
